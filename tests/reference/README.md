# Reference outputs of the BehavePlus engine

Generated with firelab/behave commit `d4acc8a074646c754673b6725234fdf3a1e9c053` (2026-09-14), g++ 13.3.0,
`-O2 -std=c++14`, all of `src/behave/*.cpp` except `client.cpp`, linked with the driver in this folder.

| File | Cases | Driver |
|---|---|---|
| `behave_surface_reference.csv` | 7,632 (53 fuel models, dead and live moisture, wind, slope) | `behave_surface_driver.cpp` |
| `behave_crown_reference.csv` | 5,265 (13 fuel models) | `behave_crown_driver.cpp` |
| `behave_crown_sr_reference.csv` | 33,696 (13 fuel models, winds to 80 km/h, Scott & Reinhardt outputs) | `behave_crown_sr_driver.cpp` |

Rebuild: `git clone https://github.com/firelab/behave && cd behave && git checkout d4acc8a`, compile the sources
(except `client.cpp`) to object files, then `g++ -std=c++14 -O2 -Isrc/behave <driver>.cpp *.o -o driver && ./driver > out.csv`.
The first two files were regenerated byte for byte with this procedure.

Archived dataset (these files, the drivers, checksums and a rebuild script): https://doi.org/10.5281/zenodo.23386397
